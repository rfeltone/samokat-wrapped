# Samokat Wrapped 2.0

Ваша история заказов Самоката в цифрах: траты, любимые товары, скидки, адреса и время доставки. Работает прямо на samokat.ru через Tampermonkey.

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/).
2. Откройте [скрипт](https://github.com/rfeltone/samokat-wrapped/raw/refs/heads/main/samokat-wrapped.user.js) и подтвердите установку. Если окно установки не появилось — создайте скрипт в Tampermonkey, вставьте содержимое [этого файла](samokat-wrapped.user.js) и сохраните.
3. Перезагрузите [samokat.ru](https://samokat.ru/), войдите в аккаунт и нажмите **«Моя статистика» → «Собрать мою статистику»**.

Для установки нужен только `samokat-wrapped.user.js`. Node.js и сборка не нужны.

## Использование

- **Пауза / Продолжить** — остановить сбор и вернуться к нему позже.
- **Обновить историю** — догрузить новые заказы.
- **Настройки** — импорт и экспорт JSON, приватный режим и удаление данных.
- После обновления скрипта перезагрузите вкладку. Выходить из аккаунта не требуется.

**При 401:** один раз откройте историю или заказ на сайте, затем вернитесь к статистике. Прокручивать всю историю не нужно. Если ошибка повторяется, автоматический сбор пока не справляется с авторизацией вашего аккаунта; доступен импорт JSON.

Данные сохраняются в вашем браузере и не отправляются разработчику. Перед сменой аккаунта удалите их в настройках.

Неофициальный проект, не связанный с Самокатом. API может меняться.
